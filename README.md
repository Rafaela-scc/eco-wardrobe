# Eco Wardrobe 🌱👕

## 🎯 Overview
**Eco Wardrobe** is a Command Line Interface (CLI) application designed to promote mindful shopping and environmental sustainability. In a world heavily driven by fast fashion and micro-trends, this tool helps users evaluate whether a clothing purchase is truly necessary, preventing impulsive buying. 

Additionally, it calculates the estimated environmental footprint—such as water usage and carbon emissions ($CO_2$) associated with the production of a t-shirt—encouraging balanced and sustainable consumption habits.

## ⚠️ The Problem
* **Landfill Waste:** A vast majority of purchased clothing ends up in landfills or is improperly disposed of.
* **Environmental Degradation:** Synthetic and discarded garments take a long time to decompose, destroying natural habitats, polluting ecosystems, and contributing significantly to global warming through harmful emissions.

## 💡 How This Solution Helps
* **Mindful Consumption:** Empowers users to make conscious purchasing decisions, drastically reducing textile waste.
* **Climate Impact Reduction:** Encourages sustainable habits that help mitigate global warming, preserve wildlife species, and protect natural resources by minimizing improper garment disposal.
